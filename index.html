    Races, gun times and bib ranges

    Press START on a race card at the gun. If you started late, by mistake, or reopened the page, set the real gun time here: the clock time (24-hour) or how long ago the gun fired. Finishers already recorded re-time themselves. Bib ranges such as 1-50, 61 pick the race for a bib automatically; blank uses the highlighted race card.

    Roster

    Optional. Import a CSV of bib and name (and race) so recorded bibs show names. Columns are bib, name, race; a header row is detected, and first and last name columns are joined. A race name that matches a race here picks that race for the bib. The roster belongs to this event and stays in this browser.

    Export and backup

    Every row has the wall-clock time, so any time can be recomputed later. A backup file restores into a new event; it never overwrites an existing one.

    Events

    Each event keeps its own races, gun times and finishers on this device.

    Start over

    Clears the finishers and gun times of this event and keeps its races. The cleared log is kept so you can bring it back.

    Keys: 0-9 bib   Enter record   Space mark time, number later   Backspace / Esc fix or clear   A-F pick race

    Hand-timed results: accuracy depends on whoever records. Everything stays in this browser; nothing is uploaded, and names from an imported roster leave only in a CSV or backup you export. Browsers can clear saved site data, so download a backup after each event. MIT licence.
